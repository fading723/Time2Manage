# ⏱️ 时间有迹 · Time2Manage

<img src="time2manage/assets/app.png" width="72" alt="时间有迹图标">

一款 Windows 本地时间记录工具，帮你看清时间花在哪里，也记住每天的想法与收获。

**自动记录软件使用 · 分钟时间轴 · 手动专注 · 此刻日记 · AI 每日复盘**

## 🚀 下载与安装

1. 前往 [Releases](https://github.com/fading723/Time2Manage/releases/latest)，下载 **Time2Manage-Setup-2.1.2-x64.exe**。
2. 双击安装程序，按向导完成安装，无需安装 Python或手动配置运行文件。
3. 从桌面或开始菜单的「时间有迹」快捷方式启动。

安装到当前 Windows 账号，无需管理员权限。安装向导提供桌面快捷方式选项；可在 Windows「已安装的应用」中卸载。更新安装及卸载保留本地记录、日记和 API 设置。更新前请从系统托盘退出正在运行的时间有迹。

发行版使用本项目的头像图标。最小化后，软件会收起到右下角系统托盘；点击图标即可重新打开。图标可能位于「隐藏图标」菜单中。

## ✨ 功能一览

| 功能 | 可以做什么 |
| --- | --- |
| 自动记录 | 记录已添加软件的前台使用时间，后台运行不计时 |
| 分钟时间轴 | 放大到 1 小时，查看每一分钟的软件使用秒数 |
| 日／周／月统计 | 查看累计时长、软件占比、活动节奏与趋势 |
| 手动专注 | 使用快捷键开始和结束，独立统计专注时间 |
| 此刻日记 | 快捷键唤起输入框，保存内容和精确到秒的时间 |
| AI 每日复盘 | 用自己的 API，结合软件记录、专注和日记复盘 |
| 本地存储 | 数据实时保存，自动备份，可导出 CSV |

## 🖥️ 自动记录软件使用

预置 **Edge、VS Code、Codex、微信和 QQ**。在「软件管理」中可添加、编辑、删除软件，也可用「识别前台软件」捕获进程名。

- 自动记录随软件启动，无需点击「开始手动专注」。
- 只记录当前前台的软件；后台挂着不计时。
- 默认空闲 **60 秒**后暂停，可在设置中调整为 5–3600 秒。阅读或看视频时可适当调大，超时前的宽限时间会计入。
- 锁屏和休眠期间不补记软件使用时间。
- 软件增删、改名后，概览和时间轴立即刷新。删除后停止记录并隐藏其统计，原始记录仍保留在本地。

进程名使用 `example.exe` 格式；同一软件有多个进程时，用英文逗号分隔。Codex 的部分桌面发行版使用 `ChatGPT.exe`，默认映射已包含。

## 📊 读懂时间轴与统计

时间轴提供 **全天、6 小时、1 小时**视图，左右箭头移动观察范围。点击轨道或输入 `HH:mm`，即可查看这一分钟内各软件和手动专注的实际秒数；悬停可查看区间起止时间。

| 指标 | 含义 |
| --- | --- |
| 软件累计时间 | 已添加软件的前台使用时长之和 |
| 专注累计时间 | 你手动开始、结束的专注时长 |
| 活动覆盖时间 | 软件与专注区间的并集，重叠时间只计算一次 |

软件和手动专注可以重叠，因此不能把两项累计时长直接相加当作工作时间。同一分钟内切换过多个软件，会分别显示在各自轨道上。

点击小时热力图可放大该时段，点击周／月趋势柱可查看对应日期。采样间隔约 0.5 秒，切换边界可能存在一个采样间隔的误差；未记录的时段不代表没有工作。

## 🎯 专注与日记快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + Alt + F` | 开始／结束手动专注 |
| `Ctrl + Alt + J` | 打开日记输入框 |
| `Ctrl + Enter` | 保存日记 |

两组全局快捷键都可以修改，最小化到托盘后仍然有效。快捷键被其他软件占用时会提示，并保留原设置。

手动专注独立于自动记录，键鼠空闲时仍计时，休眠间隔不补记。日记在保存时记录本地时间，精确到秒；在「此刻日记」页面查看，也可供 AI 复盘使用。

## 🤖 配置每日 API 复盘

1. 打开「设置 → 每日复盘 API」，填写 **API 地址、模型 ID 和密钥**，保存设置。
2. 点击「测试连接」。这一步只发送连接测试文本。
3. 选择要复盘的日期，进入「每日复盘 → 预览并生成复盘」。
4. 查看提示词和当天数据包，点击「确认发送并生成」。
5. 结果生成后自动保存在本地，选择对应日期即可再次查看。

支持 Chat Completions 兼容接口。API 地址可填写服务商基础地址，如 `https://你的服务商/v1`，也可填写完整接口地址。本机模型可使用 `http://127.0.0.1:端口/v1`，无密钥时留空；远程接口使用 HTTPS。

默认提示词会引导模型结合分钟使用记录、去重时长和日记分析一天，区分事实与推测，并给出明日行动建议。提示词可以自行修改或恢复默认。

## 🔒 本地数据与隐私

记录保存在当前 Windows 账号的本地目录：

```text
%LOCALAPPDATA%\Time2Manage\usage.sqlite3
```

- 软件记录、专注、日记、复盘及设置均保存在本地，重启后继续读取。
- API 密钥通过 Windows DPAPI 加密保存，绑定当前 Windows 账号。密钥输入框留空会保留已保存的密钥；勾选清除后保存即可移除。
- 不收集网页地址、窗口标题或键鼠输入内容。
- 只有测试连接或确认生成复盘时，才连接你配置的 API。生成复盘会发送预览中的当天记录和日记；服务商可能保留收到的数据。
- 仓库与 Release 包含应用源码、运行资源和头像图标，不包含个人使用记录、日记、API 配置、密钥、备份或本机截图。

## 💾 备份与导出

启动、每 5 分钟及保存退出时，会自动备份到数据目录中的 `backups/usage_日期.sqlite3`。

「设置 → 本地数据」可打开目录或另存完整数据库备份。导出 CSV 包含所选日期的软件／专注区间、起止时间、时长秒数及日记。

恢复备份前先保存退出软件，再用备份替换数据库。若目录中存在同名 `-wal` 或 `-shm` 文件，先将其移出。更换电脑或 Windows 账号后，需要重新配置加密保存的 API 密钥。

## 🛠️ 从源码运行

建议使用 Windows 与 Python 3.14。

```powershell
python -m pip install -r requirements.txt
python main.py
```

运行测试和构建发行包：

```powershell
python -m unittest discover -s tests -v
python tests/ui_smoke.py
python tests/tray_smoke.py
.\build.bat
.\build-installer.bat
```

应用构建结果位于 `release/Time2Manage/`，安装包位于 `installer-output/`。构建安装包需要安装 [Inno Setup 6](https://jrsoftware.org/isdl.php)，并让 `ISCC.exe` 可从 PATH 调用，或安装在其默认目录。界面与托盘集成测试使用独立数据，不读取真实记录；API 集成测试使用本机模拟接口。

体验演示数据：

```powershell
python main.py --demo --data-dir build/demo-data
```

界面由 PySide6 承载，本地静态资源直接嵌入窗口，不启动本地 HTTP 服务。
